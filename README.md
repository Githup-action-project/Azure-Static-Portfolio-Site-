# Mohammed Ibrahim - Azure Static Portfolio Site

Welcome to my personal portfolio project, built using modern cloud and DevOps technologies. This site showcases my skills, projects, and contact information, and is hosted on Azure Static Web Apps with automated deployment via GitHub Actions.

---

## 🚀 Project Overview

This is a responsive and modern portfolio website designed to highlight my expertise in:
- Cloud technologies
- Infrastructure as Code
- CI/CD automation

The site is built with HTML and Tailwind CSS and deployed using Terraform and GitHub Actions.

---

## 🧰 Technologies Used

- **Terraform** – Infrastructure provisioning
- **Azure Static Web Apps** – Hosting the portfolio site
- **GitHub** – Source control and workflow automation
- **GitHub Actions** – CI/CD pipeline for automatic deployment
- **Tailwind CSS** – Styling and responsive design
